🤔 What is WebAssembly?

Portable binary and text code format for compiling and running programs in the browser at near native speeds.

C source code

int factorial(int n) {
  if (n == 0) {
    return 1;
  } else {
    return n * 
      factorial(n - 1);
  }
}

.wat text format

    ...)

First announced in 2015 and heavily inspired by asm.js project from Mozilla.

✨ WebAssembly support & features

Open standard with support across all current major desktop and mobile browsers.
Can be targetted from a variety of compiled and interpreted languages - including Python and R .
Evolving standard - with new features added via a documented standarization process .

❓ Why is this interesting for ARC?

Opens up lots of avenues:

  • Web dashboards without need for server-side computations.
  • Simple web apps without specific web-dev experience.
  • Live examples in documentation websites and slides.
  • Interactive course material and exercises.
  • Easily deployable and acccessible teaching environments.

⚡ Emscripten

Open-source compiler toolchain outputting to WebAssembly.

Allows compiling C, C++ and other LLVM supported languages.

Provides support for common APIs such as OpenGL (via WebGL) and Portable Operating System Interface (POSIX).

Some changes usually needed to native code when porting - for example how main loop is defined & adapting file handling.

Example:

hello_world.c
#include <stdio.h>

int main() {
  printf("Hello, world!\n");
  return 0;
}

Can be compiled to JS using

emcc hello_world.c -o hello_world.js

or HTML generated using

emcc hello_world.c -o hello_world.html

🐍 Pyodide

Pyodide is a WebAssembly port of CPython using Emscripten.

Provides support for most of the Python standard library (exceptions include multiprocessing & threading).

As well as a Python runtime / REPL, Pyodide provides:

  • micropip package manager for installing packages,
  • a JavaScript ↔︎ Python foreign function interface.

📦 Pyodide packages

Packages without native extensions can be installed directly from pure Python wheels on PyPI using micropip.

Pyodide provides WebAssembly distributions of many popular 3rd party packages such as NumPy, SciPy and Matplotlib.

📈 Pyodide plotting

Pyodide’s JavaScript API allows linking to a HTML Canvas element that can be used to display graphics.

This allows seamless plotting using packages such as Matplotlib and Plotly in the browser.

🏗️ Pyodide package infrastructure

Currently package specific (conda-style) recipes are hosted in pyodide-recipes repository.

Emscripten-forge also maintains recipes for both Python and non-Python packages that can be installed with micromamba.

PEP 783 proposal to add a new pyemscripten platform tag for package distributions was recently accepted.

Will allow building and publishing Pyodide compatible distributions directly to indices such as PyPI.

cibuildwheel 2.19+ supports building binary wheels with Pyodide as a target

🇷 WebR

WebR is an R runtime compiled to WebAssembly using Emscripten for use in the browser, initially released in 2023.

Packages can be installed using webr::install function

Pure R packages can generally be used directly, while those using C/C++/Fortran may require build adjustments.

📊 Interactivity and dashboards

Quarto Live (which was used to produce these slides!) supports interactivity via ObservableJS

Code is reactively executed when UI elements such as sliders and menus are updated.

There are also various other dashboard / interactivity frameworks:

  • Shinylive - R & Python Shiny applications running client-side.
  • Stlite - WebAssembly port of Streamlit.
  • Gradio-Lite - run Gradio applications in the browser.
  • marimo - reactive notebook with support for Pyodide kernels.

// From @mbostock/debouncing-input
function debounce(input, delay = 1000) {
  return Generators.observe(notify => {
    let timer = null;
    let value;
    function inputted() {
      if (timer !== null) return;
      notify(value = input.value);
      timer = setTimeout(delayed, delay);
    }
    function delayed() {
      timer = null;
      if (value === input.value) return;
      notify(value = input.value);
    }
    input.addEventListener("input", inputted), inputted();
    return () => input.removeEventListener("input", inputted);
  });
}

📌 Summary and outlook

  • WebAssembly is an increasingly mature technology with broad browser and language support.
  • Pyodide and WebR make it possible to easily create web-based interactive apps without server-side infrastructure.
  • Package support can be problematic but situation is improving over time.
  • Initial load of Pyodide / WebR can be slow (~5-10s).
  • Interpreted code slower to run (Pyodide reports 3 to 5× slower) but compiled extension performance closer to native.
